## Xray VLESS + Reality — Автоматическая установка

Скрипт для быстрой установки **Xray-core** с протоколом **VLESS + Reality** на VPS. Без доменов, без сертификатов, без панелей — одна команда и готово.

Настроен под ТСПУ 2026: два транспорта на одном порту 443 — **XHTTP** (основной) и **TCP + Vision** (запасной). После установки сервер сам проверяет себя клиентом Xray.
---

## Требования

- VPS с **Ubuntu 22.04** или **24.04** (x64/arm64)
- **1 CPU / 512 MB RAM / 10 GB** диска
- Root-доступ
- Домен **не нужен**

---

## Установка

```bash
wget -qO install_xray.sh https://raw.githubusercontent.com/0x0f80/xray-reality-setup/main/install_xray.sh && bash install_xray.sh
```

Скрипт спросит:

1. **Режим** — обычный (рекомендуется) или режим совместимости, см. ниже
2. **Порт** — 443 по умолчанию
3. **Сайт для маскировки** — скрипт сам проверит кандидатов и предложит рабочий

После установки сервер проверит сам себя и покажет две ссылки (XHTTP и Vision) и QR-код.

### Что настраивается автоматически

UFW (файрвол) · Fail2Ban (защита SSH) · TCP BBR · Nginx-заглушка на порту 80 · Ротация логов (средствами установщика Xray)

## Обычный режим или режим совместимости?

| | Обычный | Совместимости |
|---|---|---|
| **Версия Xray** | v26.10.21 (свежая, с исправлением безопасности) | v26.7.28 |
| **Отпечаток в ссылках** | chrome | edge |
| **TLS-приветствие** | ~1,8 КБ — два пакета | ~0,5 КБ — один пакет |
| **Когда выбирать** | Всегда, если работает | Если сервер исправен, а подключение из вашей сети висит |

Сервер Xray новее 26.9.8 принимает только постквантовое TLS-приветствие (отпечатки chrome, firefox, safari). Оно не помещается в один пакет, а в части российских сетей, чаще мобильных, второй пакет теряется ([Xray #7220](https://github.com/XTLS/Xray-core/issues/7220), [#7259](https://github.com/XTLS/Xray-core/issues/7259)). Режим совместимости ставит версию, которая принимает и короткое приветствие edge. Минус — в ней нет осенних исправлений Xray.

**Как понять, что нужен режим совместимости:** `xraystatus` показывает, что самопроверка пройдена, а с телефона подключение висит. Тогда переустановите сервер и выберите вариант 2.

## XHTTP или Vision?

Каждый пользователь получает обе ссылки — они работают на одном порту.

| | XHTTP | TCP + Vision |
|---|---|---|
| **Роль** | Основная | Запасная |
| **Соединений к серверу** | Не больше 3 | По одному на каждый запрос |
| **Когда брать** | Всегда | Если XHTTP не подключается или нужна макс. скорость загрузок |

ТСПУ замораживает узел, если к одному SNI идёт больше 3 параллельных TLS-соединений с отпечатком Chrome. XHTTP укладывается в этот лимит, Vision — нет.

## Самопроверка

Клиент Xray на самом сервере подключается к нему по обеим ссылкам. Так видно, исправен ли сервер, ещё до того, как вы импортируете ссылки в приложение. Самопроверка запускается:

- в конце установки;
- в `xraystatus`;
- после смены сайта маскировки (`xtarget`) — не прошла, и прежний сайт возвращается сам;
- после обновления (`xupdate`) — не прошла, и прежняя версия возвращается сама.

## Клиенты

Нужен клиент на ядре **Xray 26.3.27 или новее**.

| Платформа | Приложения |
|-----------|-----------|
| **Android** | [v2rayNG](https://github.com/2dust/v2rayNG), Happ |
| **iOS** | [Happ](https://apps.apple.com/us/app/happ-proxy-utility/id6504287215) |
| **Windows** | [v2rayN](https://github.com/2dust/v2rayN) |

> **NekoBox, Hiddify, Throne, Karing не подойдут.** Они на ядре sing-box: XHTTP не умеют, а к серверу этого скрипта не подключаются ни в одном режиме.

## Обновление ядра

```bash
xupdate
```

Перед заменой проверяет конфиг, после — запускает самопроверку. Если что-то не так, возвращает прежнюю версию. В режиме совместимости предупредит, что новые версии не принимают отпечаток edge, и предложит перевести ссылки на chrome. После обновления сервера обновите и клиенты: версии должны быть близки.

## Удаление

```bash
bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ remove --purge
rm -rf /usr/local/etc/xray
rm -f /usr/local/bin/{x,mainuser,newuser,rmuser,sharelink,userlist,xraybackup,xraystatus,xupdate,xtarget}
rm -f /usr/local/lib/xray_link.sh
rm -f /etc/fail2ban/jail.d/xray.conf
```
